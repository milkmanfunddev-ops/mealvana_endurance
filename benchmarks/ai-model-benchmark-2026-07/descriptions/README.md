# Text descriptions

`descriptions.json` holds the text inputs for the `describe-meal` arm of the benchmark:

- **10 long descriptions** (`long-01 … long-10`) — detailed, chatty, how someone dictates a meal.
- **10 short descriptions** (`short-01 … short-10`) — terse quick-logs.

Each entry carries an `id`, a `meal` type (breakfast / lunch / dinner / snack), and the `text`.
Written to sound like a real athlete recording a meal — varied specificity (some exact grams/brands,
some vague), some self-corrections, and a few endurance-fueling moments (pre-ride carbs, on-bike gels,
recovery shake). Draft — edit freely before the run.
