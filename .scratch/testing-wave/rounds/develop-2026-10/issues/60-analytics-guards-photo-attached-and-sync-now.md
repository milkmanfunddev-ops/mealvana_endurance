**Decisions:**
- `integration_sync_started` is a new event, not a property on the connect event, so the connect funnel (`integration_connect_started` → `_success`/`_failed`) counts connects only. Mixpanel has no dashboard reading these names in the repo (grep of `docs/` and `lib/` finds no other reader).
- A cancelled or failed pick sends no analytics event. The failed pick already reports `degraded` (`log_meal_screen.dart:1996-2004`); a cancel is the athlete's choice and needs no record.
- `DeviceInfoService.deviceId` returns a per-call fallback (`device_<ms>`) before `initialize()` has run (`device_info_service.dart:88-93`). Startup initialises it before analytics (`app_startup_service.dart:417`), and Connected Apps is reached after startup, so the fallback is not expected here; no new handling.
