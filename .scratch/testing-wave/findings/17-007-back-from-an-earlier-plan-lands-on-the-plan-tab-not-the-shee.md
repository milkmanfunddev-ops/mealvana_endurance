# 17-007 · Back from an earlier plan lands on the Plan tab, not the sheet

- status: open

1. Opening a row closes the sheet before pushing the plan view, so Back returns to the Plan tab. Looking through several old plans takes ⋮ → Previous plans → scroll → row each time, and every open refetches the list (see 17-003).
2. Idea: push the plan view over the sheet (or reopen the sheet at its scroll position on Back).

**Expected.**
An athlete can step through earlier plans without starting over each time.
