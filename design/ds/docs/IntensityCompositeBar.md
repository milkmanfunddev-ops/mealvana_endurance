# IntensityCompositeBar

Slim (4 px) fully-rounded full-width intensity readout for the create flow: segment widths are the zone percentages, painted with the brand zone tokens — electrolyte Conversational (Z1–Z2), orange Tempo (Z3–Z4), dragonfruit All-Out (Z5+). Display only; `enabled={false}` dims the segments while a different estimate mode is active.

```tsx
<IntensityCompositeBar conversationalPct={70} tempoPct={25} allOutPct={5} />
```

**Dart source:** `lib/shared/widgets/kyle_design/inputs/intensity_composite_bar.dart` (library) — spec `docs/ssot/spec/design/surfaces/create-flow-fueling-controls.md`, reference `prototypes/create-activity-plan/v1.html`
