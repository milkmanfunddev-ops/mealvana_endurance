# ActivityRow

A workout card on the fuel timeline: 56 px electrolyte chip with the sport glyph, caps title, optional `verified="Garmin"` pill (electrolyte border), detail line, orange `fuelLine`. Planned workouts have no verified pill. Use `daysAway` for event lists.

```tsx
<ActivityRow sport="swim" title="Swim" detail="2,000 yd · 40 min" verified="Garmin" fuelLine="Pre · During · Recovery fuel >" />
```
