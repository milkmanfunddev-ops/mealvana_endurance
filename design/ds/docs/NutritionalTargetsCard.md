# NutritionalTargetsCard

The activity-details hero: "Your Nutritional Targets" with carbs, protein and fluids rings. Values are what has been planned so far; targets default to the reference athlete (97 g / 23 g / 444 ml) — always pass real targets.

```tsx
<NutritionalTargetsCard carbs={72} protein={18} fluids={300} targets={{carbs:97,protein:23,fluids:444}} />
```
