# Icon

Font Awesome solid glyphs as inline SVG, named exactly like `FontAwesomeIcons.*` in the Flutter app (`personRunning`, `utensils`, `calendarCheck`, `gear`…). 13–16 px inline with text, 20–24 px inside an `IconChip`. Colour comes from `currentColor`. No emoji anywhere.

```tsx
<Icon name="personSwimming" size={24} />
<Icon name="plus" size={12} />  {/* inside a dashed Add button */}
```
