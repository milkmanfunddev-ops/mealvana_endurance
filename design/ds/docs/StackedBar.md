# StackedBar

Done / planned / remaining as three pill segments proportioned to a total: filled electrolyte, electrolyte outline, faint outline. Labels sit under the ends.

```tsx
<StackedBar segments={[{value:411,kind:"done",label:"411 done"},{value:519,kind:"planned",label:"519 planned"},{value:120,kind:"remaining"}]} />
```
