# MacroStat

A phase-card figure: Sansita 30 value with the unit run together, uppercase label, optional range rail with a diamond marker. Electrolyte for the targets the plan hits; cream for sodium.

```tsx
<MacroStat value="68g" label="Carbs" color="var(--me-electrolyte)" range={{min:"50g",max:"190g",position:0.13}} />
```

**Dart source (promote from):** `lib/features/nutrition_plan/presentation/widgets/fuel_log/fuel_log_section_widget.dart (targets + range rail)`
