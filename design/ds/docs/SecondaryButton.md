# SecondaryButton

Outlined pill. `size="sm"` with `outline="dashed"` is the timeline's `+ Add Food` / `+ Add Activity` pair (neutral vs orange tone). `size="md"` (56 px, Sansita label) is the secondary form CTA beside a `PrimaryButton`.

```tsx
<SecondaryButton size="sm" outline="dashed" icon={<Icon name="plus" size={12} />}>Add Food</SecondaryButton>
<SecondaryButton size="sm" outline="dashed" tone="orange" icon={<Icon name="plus" size={12} />}>Add Activity</SecondaryButton>
```
