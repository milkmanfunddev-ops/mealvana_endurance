# Banner

Outlined notice with a leading glyph, bold title, muted detail and an expand chevron. Orange by default (the pin-honoring banner); pass `color` for other tones.

```tsx
<Banner title="Some pins honored, some skipped" detail="3 honored · 1 skipped" onExpand={toggle} />
```

**Dart source (promote from):** `lib/features/formula_kit/presentation/widgets/pin_status_banner.dart`
