# WeekStrip

The seven-day header: letters, big Compadre Wide numbers, cream selected square, electrolyte dots for days with entries. Always seven days; `selected` is an index.

```tsx
<WeekStrip days={[{day:23,letter:"S",hasEntries:true},…]} selected={2} onSelect={setDay} />
```

**Dart source (promote from):** `lib/features/fuel_timeline/presentation/widgets/fuel_timeline_day_header.dart`
