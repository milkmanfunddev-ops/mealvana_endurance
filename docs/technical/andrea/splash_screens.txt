Generating Custom Splash Screens with Flutter Native Splash
When your app is launched from a cold start, the native app shows a splash screen until runApp is called and Flutter takes over.

If you want to change the splash screen (which is white by default), you need some platform-specific configuration. And thanks to the flutter_native_splash package, you can customize the background color, splash image, dark mode, and other options.

And in this lesson, we’ll learn how to use it by changing the splash screen of the Flutter Ship app:

Transition from the native splash screen to the Flutter welcome screen
How to use flutter_native_splash
First, add flutter_native_splash as a dev dependency and install the latest packages:


Copy
dart pub add dev:flutter_native_splash
flutter pub get
Then, go to the bottom of the pubspec.yaml file and add this code:


Copy
# Flutter Native Splash configuration
flutter_native_splash:
  color: "#ffffff"
  image: "assets/android/app-icon-foreground.png"
  android_12:
    color: "#ffffff"
    icon_background_color: "#FFFFFF"
    image: "assets/android/app-icon-foreground.png"
From Android 12 onwards, the splash screen is handled differently than in previous versions, as explained here. As a result, you can set some specific parameters for Android 12+. Read the package instructions about setting the splash screen for all the details.

After saving, run this:


Copy
dart run flutter_native_splash:create

Light and Dark Mode
Showing the app icon on a plain background is easy enough, but flutter_native_splash can do much more than that.

For example, you can customize the background colors in light and dark mode on Android, iOS, and web:


Copy
# Flutter Native Splash configuration
flutter_native_splash:
  color: "#ffffff"
  color_android: "#ffffff"
  color_dark_android: "#121212"
  color_ios: "#ffffff"
  color_dark_ios: "#121212"
  color_web: "#ffffff"
  color_dark_web: "#121212"
  image: "assets/android/app-icon-foreground.png"
  android_12:
    color: "#ffffff"
    icon_background_color: "#FFFFFF"
    image: "assets/android/app-icon-foreground.png"
    color_dark: "#121212"
    icon_background_color_dark: "#121212"
    image_dark: "assets/android/app-icon-foreground.png"
Then, you can run this command again to update the splash screens:


Copy
dart run flutter_native_splash:create
As a result, whenever you use your device or browser in dark mode, the dark launch screen will show as well:

Transition from the native splash screen to the Flutter welcome screen (web, dark mode)
You can toggle between light and dark mode on iOS and Android by following these steps:

iOS (simulator): go to Settings > Developer > Dark Appearance
iOS (real device): go to Settings > Display & Brightness > Appearance
Android: go to Settings > Display > Dark Theme

Additional configuration
In addition to the above, Flutter Native Splash also supports many extra features, including:

Custom background image
Branding image
Android 12 splash screens
Preserving the splash screen while the Flutter app is initializing, as described here.
To learn about all the supported parameters, read: Setting the splash screen
