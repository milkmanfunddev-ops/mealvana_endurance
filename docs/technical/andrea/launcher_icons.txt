Generating App Icons with Flutter Launcher Icons
In this lesson, we’ll learn how to change the default Flutter app icon to a different one on iOS, Android, and web using the flutter_launcher_icons package:

iOS home screen showing a bunch of new Flutter apps with the standard icon
For convenience, we’ll use the starter project from the previous module since it already contains a custom app icon we can use.

This lesson is about generating launcher icons for iOS, Android, and web from a source image that is already provided. In the coming lessons, I’ll share some tips for designing your own icons following Apple and Android icon guidelines (including adaptive icons on Android).

Starter Project
If you haven’t already done so, please grab the source code for the Flutter Ship app from GitHub and switch to the m01-starter branch:


Copy
git clone https://github.com/bizz84/flutter_ship_app
cd flutter_ship_app
git switch m01-starter
flutter pub get
# Open in VSCode
code .
Source Images: Overview
If you open the assets folder in the project, you’ll see the following:

Assets bundled in the starter project
Inside assets/common, there are two images that we will use to generate the iOS icons:

Icon for the Flutter Ship app
But for Android, we have an assets/android folder that contains three icons:

Android app icons are generated by combining a foreground with a background image
That’s because Android supports adaptive icons that can display differently depending on individual device capabilities and user theming.

Providing separate background and foreground images allows the Android OS to combine and show them as appropriate. For more details, check this lesson, which shows how to create a simple icon in Figma.

How to use flutter_launcher_icons
To get started, install it as a dev dependency:


Copy
dart pub add dev:flutter_launcher_icons:0.14.3
flutter pub get
Important: use version 0.14.3 or above. This fixes an issue that was causing black icons on Android on some devices.

Then, add a flutter_launcher_icons snippet at the bottom of the pubspec.yaml file:


Copy
flutter:
  uses-material-design: true
  assets:
    - assets/common/
 
# Flutter Launcher Icons configuration
flutter_launcher_icons:
  ios: true
  android: true
  image_path_ios: "assets/common/app-icon.png"
  image_path_ios_dark_transparent: "assets/common/app-icon-transparent.png"
  image_path_android: "assets/android/app-icon-android.png"
  adaptive_icon_background: "assets/android/app-icon-background.png"
  adaptive_icon_foreground: "assets/android/app-icon-foreground.png"
  remove_alpha_ios: true
  web:
    generate: true
    image_path: "assets/common/app-icon.png"
This tells flutter_launcher_icons how to generate the icons for iOS, Android, and web, using the given image paths as sources.

Note the usage of the remove_alpha_ios: true flag. This is necessary since icons with an alpha channel are not allowed in the Apple App Store.

Note about dark and tinted icons on iOS 18
Xcode 16 adds support for dark and tinted icon variants, which have been added to iOS and iPadOS 18.

To generate these variants for your iOS app, use version 0.14.0 or above of the flutter_launcher_icons package.

Then, you can specify your variants by setting these properties in your pubspec.yaml file:

image_path_ios_dark_transparent
image_path_ios_tinted_grayscale
Here’s a preview showing how to use an icon with transparent background to generate the dark and tinted icons in the Flutter Ship app:

Dark and Tinted Icons on iOS 18

Flutter Launcher Icons Checklist
To generate the launcher icons on iOS, Android, and web, follow these steps.

Flutter Launcher Icons Checklist
Design your icons
Create the source icons
Install, configure, and run flutter_launcher_icons
Run the app on each target platform
Save the changes to Git
1. Design your icons
You can use tools like Figma, Flaticon, Icon Kitchen, or Midjourney to design your icons.

Don’t forget to follow the App Icons guidelines, Google Play icon design specifications, and Android adaptive icons guide.

2. Create the source icons
Once your app icons are ready, export them to the assets folder in your Flutter project. I recommend creating a separate android folder for the Android adaptive icons:

Assets bundled in the starter project
3. Install, configure, and run flutter_launcher_icons
Run this:


Copy
dart pub add dev:flutter_launcher_icons:0.14.3
flutter pub get
Then, add a flutter_launcher_icons snippet at the bottom of the pubspec.yaml file:


Copy
# Flutter Launcher Icons configuration
flutter_launcher_icons:
  ios: true
  android: true
  image_path_ios: "assets/common/app-icon.png"
  image_path_ios_dark_transparent: "assets/common/app-icon-transparent.png"
  image_path_android: "assets/android/app-icon-android.png"
  adaptive_icon_background: "assets/android/app-icon-background.png"
  adaptive_icon_foreground: "assets/android/app-icon-foreground.png"
  remove_alpha_ios: true
  web:
    generate: true
    image_path: "assets/common/app-icon.png"
Save your pubspec.yaml and run this to generate the icons:


Copy
dart run flutter_launcher_icons
Reminder: After generating the iOS icons, you may see a warning about unassigned children. The simplest way to resolve this is to select each unassigned icon in Xcode and delete it by pressing Backspace. Alternatively, you can open the ios/Runner/Assets.xcassets/AppIcon.appiconset folder and delete all the images that are not listed in the Contents.json file. For more info, read: The app icon set “AppIcon” has an unassigned child.

4. Run the app on each target platform
Once you’re done, run the app and ensure the launcher icon looks good on each platform.

5. Save the changes to Git
Having verified that the icon looks good, you can commit all the latest changes to git:


Copy
git add .
git commit -m "Updated app icon"
