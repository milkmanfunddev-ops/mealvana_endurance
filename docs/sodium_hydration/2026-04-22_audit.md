- **All tests tightened** — permissive edge tests, missing pre-workout edge tests, Flutter parity (Examples 3 & 5), transparency-service numeric tests.
- **Per-segment `isIndoor` + running treadmill** — fix both collapses.
- **One branch, one PR** — merge `feature/garmin-brand-compliance` back to `develop`, then work directly on `develop`.

## Source-of-truth spec summary

### Shared constants (from `hydration_sodium_calc_spec.md`, `research_notes_updated.md` §1.4)

```
SWEAT_RATE_PERCENTILES  = { LIGHT: 0.90, MEDIUM: 1.28, HEAVY: 1.66 }  // L/hr
SODIUM_PERCENTILES      = { LOW: 650,  AVERAGE: 825, HIGH: 1000 }      // mg/L
SWIMMING_SWEAT_MODIFIER = 0.4
TRANSITION_FLUID_ML     = 300
TEMP_BASELINE_C         = 22          TEMP_COEFFICIENT       = 0.04 per °C   clamp [0.50, 1.80]
HUMIDITY_BASELINE_PCT   = 50          HUMIDITY_COEFFICIENT   = 0.002          clamp [1.00, 1.10]
INDOOR_MULTIPLIER       = 1.30
MIN_SWEAT_RATE          = 0.3 L/hr    MAX_SWEAT_RATE         = 3.0 L/hr
DEFICIT_THRESHOLD       = 0.02 (2% BW)
GI_CEILING_RUNNING      = 800 ml/hr   GI_CEILING_CYCLING     = 1200 ml/hr
REPLACEMENT_PCT         = { <60: 0.30, <90: 0.50, <150: 0.60, <240: 0.70, >=240: 0.80 }
PRE_FLUID_ML_PER_KG     = 6   (range 5–7)
PRE_SODIUM_TIER1_MG     = 450 (range 300–600)
PRE_FLUID_TIER2_ML      = 250 (range 200–300)
PRE_SODIUM_TIER2_MG     = 150 (range 100–200)
PRE_TIME_FULL_PROTOCOL  = 120 min     PRE_TIME_TOPUP        = 10 min
```

### Gate rule (both pre and during)
```
if duration_min < 60 AND temp_celsius < 30: gate fires
```
At exactly 60 min or 30 °C the gate does NOT fire. Temp >= 30 always bypasses the gate.

### Effective sweat rate
```
base = known_sweat_rate_ml_hr / 1000  OR  percentile[sweater_type]
effective = clamp(base × temp_mult × humidity_mult × indoor_mult, 0.3, 3.0)  // L/hr
swim segments: effective × 0.4
```

### Known-sweat-test override
Known rate replaces base; temp/humidity/indoor multipliers still compose. Known sodium concentration is used directly (no modifiers).

### Priority chain for final rate
```
final = max(pct_based, floor); final = min(final, ceiling)
```
If ceiling < floor → ceiling wins; emit "Even at maximum intake, you will exceed 2% BW loss" flag.

### Pre-workout tiers (time-based only)
| Tier | `time_before_workout_min` | Fluid | Fluid range | Sodium | Sodium range |
|---|---|---|---|---|---|
| Tier 1 | >= 120 | `BW × 6 ml` | `BW × 5`–`BW × 7` | 450 mg fixed | 300–600 |
| Tier 2 | 10..119 | 250 ml fixed | 200–300 | 150 mg fixed | 100–200 |
| Tier 3 | < 10 | 0 | — | 0 | — |

Pre-workout sodium is **not** body-weight-scaled, **not** sweat-category-dependent.

### Multi-segment (triathlon / brick)
- Per-segment loss uses swim 0.4× modifier.
- Replacement % comes from **total** duration, not per-leg.
- T1 and T2 are **fixed 300 ml each** (adjacency-detected: swim→bike = T1, bike→run = T2).
- `required_total = total_loss × replacement_pct`; transitions absorb `n × 300 ml`; remaining distributed across drinkable segments by hours.
- Floor/ceiling applied per segment.
- Run→bike redistribution: if run recommended > run_ceiling OR floor > run_ceiling, shift shortfall to bike up to its 1200 ml/hr ceiling.
- Sodium derives directly from fluid: `(fluid_ml_hr / 1000) × sodium_conc` — no independent logic.

### Safety flags
- `deficit_pct > 0.02` → "Even at the recommended intake, you may lose more than 2% body weight…"
- `deficit_pct > 0.03` → "Significant dehydration expected (>{N}% BW)…"
- ceiling < floor or redistribution caps hit → "Even at maximum intake, you will exceed 2% BW loss. Pre-hydrate aggressively."

## 🟠 Missing structural UI

### Missing Calculation collapsible on During-Fluids (P0)
The spec's `CALCULATE EFFECTIVE SWEAT RATE` / `REPLACEMENT STRATEGY` / floor/ceiling / deficit-check pipeline is the primary transparency surface. Our During-Fluids card currently has only Watch + Full Story — no Calculation section at all.

Required rendering (from `transparency_during_hydration.md`):
```
CALCULATE EFFECTIVE SWEAT RATE
① medium sweater       → 1.28 L/hr  (50th pct)
② 22°C                 × 1.0  = 1.28 L/hr
③ 55% humidity         × 1.01 = 1.29 L/hr
④ outdoor              × 1.0  = 1.29 L/hr  effective

REPLACEMENT STRATEGY
⑤ 90 min → 50% → 1.29 × 1000 × 0.50 = 645 ml/hr
────────────────────────────────────────────
   645 ml/hr × 1.5 hr = 968 ml (33 oz)
↓ floor   = (1,935 − 1,300) ÷ 1.5 = 423 ml/hr  (21 oz total)
↑ ceiling = min(800, 1,290) = 800 ml/hr (41 oz total)
   range → 21–41 oz
✓ deficit = 1,935 − 968 = 967 ml → 1.5% BW  (< 2% ✓)
```

Plus amber/green/purple callouts where the spec calls for them.
