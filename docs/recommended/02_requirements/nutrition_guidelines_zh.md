# 耐力运动员营养规划指导原则

为长时间训练或比赛日生成营养计划的算法设计原则。

---

## 高层次目标

> 根据宏量营养素需求（例如碳水化合物、钠、液体），使用食物产品混合生成个性化营养计划，满足不同比赛或训练阶段的目标，同时**易于消化**、**便于携带**和**时间安排合理**。

---

## 耐力营养计划生成的核心指导原则

### 1. 宏量营养素目标指导原则

| 营养素       | 推荐摄入量 |
|----------------|--------------------|
| **碳水化合物** | |
| • 训练前 | 1-4克/公斤体重（70公斤运动员约70-280克） |
| • 训练中 | 30-60克/小时（葡萄糖+果糖混合最多90克/小时） |
| **钠** | 300-600毫克/小时（高温时最多1000毫克/小时） |
| **液体** | 约0.4-0.8升/小时，取决于出汗率 |

---

## 需要考虑的输入参数

- 运动员体重（公斤）
- 活动类型和持续时间
- 环境条件（高温、湿度）
- 食物偏好（喜欢/不喜欢）
- 胃肠道敏感性
- 产品可获得性

---

## 按时间阶段的规划规则

### A. 训练前（开始前2-3小时）

1. 限制为3-6种不同食物以减少胃肠道压力
2. 目标是低至中等纤维和脂肪以加速消化
3. 包括易消化的碳水化合物（如燕麦片、香蕉、华夫饼、白面包、蜂蜜）
4. 避免高脂肪或高纤维食品（如燕麦棒、坚果、生蔬菜）
5. 如出汗率高则包含盐或电解质
6. 建议慢慢饮用16-24盎司液体（水+饮料粉）
7. 可选择在开始前15分钟摄入少量碳水化合物（如能量胶）

### B. 跑步期间

8. 根据持续时间匹配碳水化合物需求；每20-30分钟稳定摄入
9. 使用碳水化合物密集、便携的选项（能量胶、软糖、饮料粉）
10. 仅使用跑步时易于摄入的形式（能量胶、软糖、液体）
11. 标记跑步时不可行的食物（香蕉、三明治、燕麦片）
12. 最大化适口性+最小化复杂性（2-4种物品）
13. 偏好结合碳水化合物+钠的产品

## 产品特定实用性表格

| 产品             | 跑前 | 跑中 | 跑后 | 备注                          |
|---------------------|---------|------------|----------|--------------------------------|
| 燕麦片             | ✅ 是  | ❌ 否      | ⚠️ 也许 | 需要准备；仅跑前    |
| 香蕉              | ✅ 是  | ❌ 否      | ✅ 是   | 跑步时不可行     |
| 花生酱       | ✅ 是  | ❌ 否      | ⚠️ 也许 | 高脂肪；减慢消化      |
| 华夫饼              | ✅ 是  | ❌ 否      | ⚠️ 也许 | 易碎，跑步时难以食用 |
| 燕麦棒         | ⚠️ 不理想 | ❌ 否 | ✅ 是   | 干燥，跑步时难以咀嚼 |
| 能量胶                 | ✅ 可选 | ✅ 是 | ❌ 否    | 跑中补给的理想选择   |
| 软糖               | ⚠️ 否   | ✅ 是     | ❌ 否    | 适合跑步              |
| Tailwind饮料粉  | ✅ 是  | ✅ 是     | ✅ 是   | 结合液体+碳水化合物+钠   |
| 运动饮料        | ✅ 是  | ✅ 是     | ✅ 是   | 补给站或携带选项  |

## 算法的附加规则

18. 绝不在不实用的阶段分配食物（例如跑步期间的燕麦片）
19. 在跑步期间优先考虑易于摄入的食物（能量胶、软糖、液体）
20. 为敏感胃部调整计划（更少、更简单的物品）
21. 考虑口味疲劳（口味多样性）
22. 考虑跑中液体建议的携带水合能力
