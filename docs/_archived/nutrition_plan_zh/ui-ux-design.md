#### 1.2.2 参数分组设计
*[来源: README.md - 命令行选项章节]*

**基本参数组：**
```
运动员信息：
  --age              年龄
  --gender           性别
  --weight           体重
  --weight-unit      重量单位
  --height           身高
  --height-unit      身高单位

时间和训练：
  --time-before-activity-min  赛前时间
  --gut-training              肠道训练水平
  --preferences               偏好文件路径
```

**运动特定参数组：**
```
跑步参数：
  --sport running
  --run-pace         配速
  --run-distance     距离
  
自行车参数：
  --sport cycling
  --cycling-speed    速度
  --cycling-power    功率
  --cycling-terrain  地形

铁人三项参数：
  --sport triathlon
  --triathlon-distance  标准距离
  --swim-pace          游泳配速
  --bike-speed         自行车速度
  --run-pace-tri       跑步配速
```

## 2. 用户体验设计原则
*[来源: QUICK_START_GUIDE.md, 用户反馈分析]*

### 2.1 简化原则
- **5分钟快速开始**：提供预设模板和示例
- **渐进式复杂度**：基础功能简单，高级功能可选
- **智能默认值**：合理的默认参数减少输入

### 2.2 清晰原则
- **结构化输出**：分组展示信息
- **视觉层次**：使用缩进和符号区分层级
- **关键信息突出**：评分、总计等重要数据醒目

### 2.3 实用原则
- **真实份量**：避免0.77个苹果这样的建议
- **时间分段**：按小时展示补给计划
- **多选项提供**：给出备选方案

## 3. 错误处理与提示
*[来源: 实际使用案例分析]*

### 3.1 输入错误提示
```
错误类型示例：

[错误] 无效的运动类型
提示：--sport 必须是 running、cycling 或 triathlon 之一

[错误] 配速格式错误
提示：配速格式应为 "MM:SS"，例如 "8:00"

[错误] 偏好文件不存在
提示：找不到文件 preferences.json，请检查路径
```

### 3.2 逻辑错误提示
```
[警告] 无可行方案
原因：设置了过多"不喜欢"的食物
建议：减少限制或调整偏好设置

[警告] 营养目标冲突
原因：时间太短无法达到碳水目标
建议：增加赛前进食时间或降低目标
```

### 4.2 偏好模板库
*[来源: PREFERENCES_GUIDE.md]*

提供6种预设偏好模板：
1. **保守型新手**：熟悉食物为主
2. **运动产品型**：工程化营养优先
3. **全食物型**：天然食品偏好
4. **GI敏感型**：低纤维液体为主
5. **超长距离型**：高多样性防疲劳
6. **时间紧迫型**：快速简便无需准备
