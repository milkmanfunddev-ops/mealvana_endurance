# 通过更好的营养和碳水化合物负载实践改善耐力训练表现和舒适度

![nutrition-opportunity-tree.svg](attachment:4feb588c-3dba-46da-8a73-63a166e8eddd:nutrition-opportunity-tree.svg)

## 1. **优化表现营养**

### 1.1 **训练前适当补充燃料**

- 理解最佳碳水负载时间窗口（24小时 vs 48小时）
- 知道何时减少纤维摄入以最小化胃肠道不适
- 确定碳水负载的理想宏量营养素比例
- 将营养需求转化为膳食想法

### 1.2 **训练中适当补充燃料**

- 准确知道根据我的体型、训练强度、持续时间和其他因素（如天气或训练阶段）每小时需要消耗多少营养素（碳水化合物、水、电解质等）以及总量
- 将营养需求转化为产品和/或配方
- 消耗时机
- 根据温度、湿度、海拔进行调整
- 携带能力计算
- 产品浓度优化

### 1.3 **训练后适当补充燃料**

- 确定恢复的理想宏量营养素比例
- 恢复营养的时机
    - 在训练后30-40分钟内满足20-40g蛋白质窗口
- 将营养需求转化为膳食想法
- 快速实用的恢复解决方案

## 2. **简化跟踪和计划**

### 2.1 **让营养记录变得轻松**

- 使用语音笔记描述我吃了什么以及感觉如何
- 拍照而不是手动输入
- 从其他应用自动导入训练数据
- 在长时间训练期间设置营养时机提醒
- 在不中断训练流程的情况下记录
- 导入专业测试结果（汗液测试）
- 桥接训练与比赛日数据差距

### 2.2 **获得可操作的洞察而不感到困扰**

- 以简单的可视格式查看我是否达到碳水目标
- 跟踪营养与表现之间的模式
- 获取有效/无效内容的摘要
    - 将本周的长跑营养与上周的进行比较
    - 识别始终对我有效的食物
    - 当我持续营养不足时发出警告

### 2.3 **控制和定制我的营养计划**

- 根据我的经验调整每小时碳水目标
- 为何时摄取营养设置自定义时机
- 添加任何数据库中没有的食物（自制项目）
- 用个人偏好覆盖应用建议
- 导出计划与教练或训练伙伴分享
- 允许明智地偏离推荐
- 支持替代时机策略（按距离而非时间）

### 2.4 沟通我的营养计划

- 我希望我的教练了解我的营养计划和执行情况
- 我希望营养师看到我的营养计划和执行情况
- 与医疗专业人员分享数据

## 3. **通过实验和学习进行个性化**

### 3.1 **发现适合我独特身体的方法**

- 确定比赛前个人纤维阈值
- 在训练前优化排便时机
- 跟踪周五碳水负载与周六表现之间的相关性
- 识别引起不适的触发食物
- 与运动医学医生合作进行汗液测试
- 通过尿液图像评估我的水合状态
- 极端生理变异（大量出汗者、高钠流失）
- DIY汗液测试协议
- 渐进性肠道训练协议
- 疲劳点的模式识别（2/3撞墙）
- 产品质地/味道/温度偏好
- 跑前最佳消化/上厕所时机
- 非传统碳水来源（水果vs谷物）

### 3.2 **解决心理和社会挑战**

- 识别何时对碳水的恐惧限制表现
- 在训练期间应对节食的社会压力
- 将大量训练期间大量进食正常化
- 对感觉"轻盈"的心理偏好

### 3.3 **建立基于证据的理解**

- 以易消化的格式获取耐力营养研究
- 理解为什么碳水化合物对表现至关重要
- 了解营养不足如何影响训练适应
- 明确耐力运动员的蛋白质需求
- 理解肠道训练和吸收限制
- 向可信的专家和运动营养师学习
