# Mealvana Endurance - 应用概述

## 项目总结

Mealvana Endurance 是一款为耐力运动员设计的个性化营养规划应用，能够为长距离跑步训练日生成基于科学证据的营养补给计划。

## 目标用户

- 耐力运动员（跑步、自行车、铁人三项）
- 准备参加从5公里到超马比赛的运动员
- 寻求个性化营养指导的跑步者
- 希望优化补给策略的运动员

## 核心价值主张

生成个性化、科学化的营养计划，帮助耐力运动员：
- 在训练和比赛中优化能量供应
- 通过合理的食物时间安排预防消化问题
- 维持水分和电解质平衡
- 尊重个人食物偏好和限制

## 核心功能

### 🎯 智能食物优先级
计划优先使用你喜欢的食物，其次是愿意尝试的，避开不喜欢的食物

### 📊 基于证据的计算
基于运动营养学研究的算法（30-90克碳水化合物/小时，200-700毫克钠/小时）

### 🏃‍♂️ 个性化计划
基于距离、配速、体重和肠胃训练水平的营养计算

### 📱 设备为中心的认证
无需账户 - 一切都与你的设备绑定以保护隐私

### 🔄 多类别食物
食物可以在多个时间阶段（之前/期间/之后）被推荐

### 📏 结构化份量数据
准确的食物分量如"3杯煮熟的燕麦片"（不再需要硬编码解析）

### 💾 离线优先
使用本地存储完全离线运行

### 🎨 简洁界面
针对快速计划生成优化的 Material Design 3 界面

## 技术栈

- **前端**: 使用 Riverpod 2.x 的 Flutter（AsyncNotifier 模式）
- **后端**: Supabase（PostgreSQL + Edge Functions）
- **本地存储**: Drift SQLite 数据库
- **导航**: 带嵌套导航的 GoRouter
- **架构**: 面向功能的架构（FOA）
- **部署**: 用于代码推送更新的 Shorebird

## 成功指标

- 用户完成引导流程的比率
- 每个用户生成的计划数量
- 应用稳定性（无崩溃率）
- 用户反馈评分
- 计划有效性反馈
