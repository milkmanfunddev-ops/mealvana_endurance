# Mealvana Endurance - 需求与设计规格

## 项目概述

设计和开发一个基于证据的营养规划应用，为耐力运动员生成个性化的补给计划，涵盖跑前、跑中和跑后的营养需求。该应用遵循全面的耐力运动员营养指导原则，确保营养推荐易于消化、便于携带且时间安排合理。

## 核心需求

### 基于证据的基础
应用实施科学支持的耐力运动员营养指导原则：
- **宏量营养素目标**基于体重和运动持续时间（跑前1-4克/公斤碳水化合物，跑中总计0-60克）
- **阶段性食物选择**具有实用性约束（跑步期间不推荐燕麦片/香蕉）
- **产品特定适用性**通过数据库分类系统强制执行
- **胃肠道耐受性考虑**以最小化消化压力
- **基于持续时间的推荐**（少于60分钟不补给，较长跑步逐步增加）

完整科学基础请参见`nutrition_plan_guidelines.md`。

## 用户流程

### 1. 新手引导

创建多步骤新手引导流程来收集：

- **性别**（选择）
- **年龄或生日**（推荐生日以自动计算年龄）
- **身高**（英尺和英寸）
- **体重**（磅）
- 你跑步时带水壶吗？

*注意：美国MVP版本不需要单位切换*

### 2. 食物偏好收集

在单个屏幕上设计基于复选框的食物偏好界面：

- **选中** = 喜欢这个食物（将包含在营养计划中）
- **未选中** = 不喜欢这个食物（在营养计划中将被避免）
- **单个可滚动列表**按名称显示所有12种食物
- **全选/清除全部按钮**方便使用
- **点击食物名称**查看详细信息和营养指导

### 包含的食物项目：

**跑前食物：**

- 燕麦片（点击时出现此信息："**补充碳水，小甜心：**温和的复合碳水 = 平稳的2-3小时能量。跑前30-60分钟摄入。"）
- 华夫饼或煎饼
- 百吉饼或面包 🥯
- 花生酱
- 香蕉
- 苹果
- 果汁
- 燕麦棒
- 咖啡 ☕

**跑中食物：**

- 运动饮料
- 能量胶
- 能量软糖
- 运动饮料粉
- 枣子或干果
- 电解质片

**跑后食物：**

- 椰子水
- 蛋白质奶昔
- 蛋白质棒

### 3. 主屏幕

设计简单的输入界面：

- **距离输入**（英里）
- **平均配速输入**（分钟/英里）
- **"生成计划"按钮**
- **显示区域：**
    - 计算的宏量营养素需求
    - 跑前餐食计划（1-2小时前）
    - 跑中补给时间表（基于时间/距离）

输出的模拟示例：

### 宏量营养素目标

- **跑前碳水化合物：**70-280克（基于可用时间的1-4克/公斤）
- **跑中碳水化合物：**总计0-60克（基于跑步持续时间和肠胃训练）
- **钠：**整个跑步总计0-600毫克
- **液体：**整个跑步总计150-800毫升

### 计划

**跑前：**

1杯燕麦片 + 1根香蕉，切片 + 1杯咖啡（1小时前）

1杯橙汁（30分钟前）

**跑中：**

2个能量胶 + 16盎司运动饮料（整个跑步的总量，逐渐摄入）

**跑后：**

1个蛋白质棒（30分钟内）

2杯椰子水（30分钟内）

### 4. MVP反馈组件

创建计划生成后的反馈机制：

反馈问题1：你对这个计划的看法如何？

- 与我认为应该使用的非常接近
- 比我认为应该使用的多得多
- 比我认为应该使用的少得多

反馈问题2：你对这个小应用的看法如何？

- **选项1**："我喜欢！提醒我使用它"
    - → 链接到提醒功能
- **选项2**："它有潜力，但我需要它..."
    - → 建议文本输入字段
- **选项3**："不感兴趣"
    - → 可选原因选择

## 设计考虑

### 视觉设计

- 简洁、极简的界面
- 食物偏好的清晰复选框状态
- 点击显示每种食物的详细信息
- 户外可视性的高对比度

### 信息架构

- 营养计划应易于浏览
- 跑前和跑中部分之间的清晰分离
- 跑中物品摄入的时间/距离标记

### 用户体验

- 简单的复选框界面用于快速食物偏好选择
- 全选/清除全部按钮方便使用
- 点击食物名称查看额外详情和时间指导
- 使反馈组件不打扰但易于访问
- 新手引导步骤的进度指示器
- 初次设置后快速访问编辑偏好

## MVP成功指标

- 新手引导的完成率
- 生成计划的用户百分比
- 反馈响应率
- 用于迭代的具体反馈内容
