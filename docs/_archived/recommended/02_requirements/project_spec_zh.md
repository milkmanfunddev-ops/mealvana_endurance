# **Mealvana for Endurance Athletes — 产品功能与竞争优势**

## **一句话总结**

**Mealvana将您的训练计划转化为手中的燃料和赛道上的执行**：个性化计划、自动生成的购物和准备清单，以及设备提醒，让计划真正落地执行。

## **目标用户**

从半程马拉松到铁人三项/超马的严肃休闲到竞技**跑步者、铁人三项运动员、自行车手和超跑者**。适用于偏好**运动产品或真实食物**的运动员，以及有**胃肠道敏感、热/汗挑战或女性特定需求**的运动员。

---

# **核心优势**

大多数应用只停留在"每小时60-90克碳水化合物"。**Mealvana完成了闭环**：

1. **计划**（根据训练负荷、比赛、天气、出汗、胃肠道、周期阶段个性化）
2. **采购**（自动列出杂货和产品；DIY混合配方；成本优化器）
3. **执行**（推送到Garmin/Wahoo/Apple Watch；基于时间的提醒；瓶子计算；补给站感知）
4. **学习**（合规性+胃肠道日记→适应性下一计划）

---

# **核心工作（基于需求数据）**

- **比赛日燃料计划**：每小时碳水化合物、液体、钠、咖啡因剂量、携带策略。
- **训练燃料**：长跑/骑行、双日训练、肠道训练进展。
- **比赛周**：碳水化合物负荷、低残渣准备、水分补充。
- **恢复**：训练后立即和多日重建。
- **炎热天气和出汗变化**：环境适应。
- **胃肠道故障排除**：按成分特征的替代方案；口味疲劳轮换。
- **"购物清单到比赛包"桥梁**：买什么、如何混合、打包什么。

# **产品支柱和关键功能**

## **1) 个性化引擎**

- **输入**：运动和赛事（半马→铁人三项/超马）、目标时长/功率/配速、训练日历导入、身高/体重、出汗自测、钠偏好、胃肠道历史、饮食模式、预算、品牌/库偏好。
- **女性模式**：可选的**周期感知调整**（水分、铁提示、黄体期碳水化合物强调）。
- **环境感知**：比赛**预报和海拔**→调整液体/钠和碳水化合物形式（饮料vs凝胶）。

## **2) 计划构建器**

- **比赛计划向导**：创建**分钟级时间表**（碳水化合物、液体、钠、咖啡因）、**携带计划**（多少凝胶/瓶子；浓度）和**补给站逻辑**（拿什么、跳过什么）。
- **训练日自动计划**：基于TrainingPeaks/Strava/Garmin的锻炼类型，推荐**训练前燃料、训练中燃料和恢复**，配合肠道训练进展。
- **碳水化合物负荷组合器（48-72小时）**：按体重的每日克数、低纤维指导、示例菜单。
- **恢复构建器**：3个时间窗口（0-30分钟、30-90分钟、晚上），提供**真实食物+产品**选项。

## **3) 真实食物平等+产品智能**

- **双重数据库**：品牌产品**和**全食物（香蕉、米饼、枣、椒盐卷饼、花生酱果酱等）。
- **等效替换**："1个Maurten 100 ≈ 25克碳水化合物→如果凝胶让您不适，尝试½花生酱果酱+8个椒盐卷饼。"
- **DIY混合模式**：简单糖/盐比例、瓶子计算、**口味轮换**对抗口味疲劳。
- **成本优化器**：用**更便宜的组合**（真实食物或批量混合）达到目标，显示**月度节省**。

## **4) 执行模式（大多数应用失败的地方）**

- **设备推送**：将燃料步骤/提醒发送到**Garmin/Wahoo/Apple Watch**（例如，每15分钟20克碳水化合物；啜饮提示）。
- **瓶子和凝胶计算**：浓度计算器+"精确勺数"，如果掉落凝胶的**备用计划**。
- **比赛卡**：可打印/移动卡：时间表、总计、打包清单、**"如果"应急方案**。
- **准备清单**："晚上8点混合瓶子（每瓶X勺），将凝胶贴到上管，如果>80°F则冷冻瓶子。"

## **5) 学习和适应**

- **比赛期间点击记录**（可选）或**同步锻炼后自动对账**：您与计划的接近程度。
- **胃肠道日记**：标记问题和成分→**避免启发式**（例如，麦芽糊精重的凝胶）。
- **肠道训练评分**：显示耐受性向目标碳水化合物/小时改善的每周指标。
- **提醒**："明天硬训练→晚餐添加30-60克碳水化合物。"

## **6) 教练和团队控制台（B2B优势）**

- **按赛事模板**；批量分配；监控合规性；运动员标志（低摄入、反复胃肠道问题）。
- **评论/调整**比赛卡；导出到运动员设备。
- 团队/俱乐部的分层定价。

# **用户场景**

## **1) Jess（首次马拉松，4:15目标，紧张胃）**

- 连接TrainingPeaks；选择**马拉松-芝加哥**。
- Mealvana构建**比赛周**：2天碳水化合物负荷（~8-10克/公斤），低残渣清单；比赛日早餐（赛前2-3小时）。
- **比赛计划**：每小时60-75克碳水化合物，每小时400-600毫升液体，钠400-600毫克/升，赛前100毫克咖啡因+20公里时50毫克。
- **真实食物倾向**：计划使用**咀嚼物+运动饮料**，如果凝胶感觉有风险，**香蕉替代**排队。
- **执行**：Apple Watch每15分钟提醒；可打印**比赛卡**；打包清单。
- **之后**：记录第10英里轻微晃动→应用建议下次**更小、更频繁的啜饮**。

## **2) Omar（奥斯汀70.3，"咸汗"，热天骑行）**

- 输入出汗测试估计；选择**自行车重燃料**和**高钠**。
- 应用设置**自行车每小时90克碳水化合物，跑步60克**，**每小时600-800毫升液体**，**1000-1500毫克钠/升**。
- **瓶子计算**：自行车上两个浓缩瓶子+补给站水；**备用凝胶**在便当盒。
- 提供**DIY混合**降低成本；显示这场比赛比全凝胶**节省28美元**。
- 推送到Garmin；骑行电脑弹出**"啜饮/吃"**提醒。
- 报告：跑步完美→应用锁定这个钠目标用于未来热天比赛。

## **3) Lin（女性马拉松运动员，黄体期比赛周，之前低铁）**

- 启用**女性模式**；在比赛周标记**黄体期**；应用推荐**稍高的总碳水化合物**、**水分补充**和**本周早些时候的富铁餐**。
- 选择**胃肠道温和**选项（Maurten风格凝胶或米球）。
- 应用安排**咖啡因**保守剂量避免紧张。
- 购物清单包括**铁支持食物**（配维生素C）。
- 赛后：记录零胃肠道问题→计划标记为"粘性"。

## **4) Diego（砾石世纪，真实食物偏好）**

- 选择**真实食物优先**；应用构建**米饼、枣、花生酱果酱**菜单，加上**电解质片**。
- **补给站感知**：使用路线图计划在哪里拿什么；最小化重携带。
- 成本优化器显示比凝胶**便宜>50%**，同时达到**每小时75-90克**。
- 通过Wahoo提醒执行；骑行后：轻微口味疲劳→应用下次轮换口味。

## **5) 教练Maya（20名运动员铁人三项队）**

- 导入名单；应用**70.3模板**和热变体到8名参加查塔努加比赛的运动员。
- 看到合规仪表板：3个燃料不足的长骑行被标记。
- 留下评论；推送更新的比赛卡；打印团队**"特殊需求"**打包表。
- 赛季结束导出**合规性vs PR改善**用于营销。

# **示例输出（用户实际看到的）**

**比赛卡 — 70.3（Omar）**

- **早餐（05:30）**：110-130克碳水化合物，低纤维；500毫升电解质（750毫克钠）。
- **游泳**：可选赛前20-30分钟100毫克咖啡因。
- **自行车（2小时45分钟）**：每小时90克碳水化合物通过2×浓缩瓶子+每小时1个凝胶；每小时700毫升液体；**1500毫克钠/升**。**每15分钟提醒**。
- **跑步（1小时55分钟）**：每小时60克碳水化合物通过补给站饮料+咀嚼物；每小时500-600毫升；30-40分钟时100毫克咖啡因。
- **总计**：~360-380克碳水化合物，~3.2-3.6升液体，~4.5-5.0克钠。
- **打包清单**：6个凝胶（2个含咖啡因），2×750毫升瓶子（每个X勺），6个咀嚼物，盐片备用，胶带，瓶子。
- **如果**：掉落一个凝胶→下次提醒时喝半瓶+1个咀嚼物。
