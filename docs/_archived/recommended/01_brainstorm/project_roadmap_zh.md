# Mealvana Endurance 路线图

## 概述
这个路线图概述了Mealvana Endurance营养规划应用从MVP到全功能平台的开发阶段。

## 阶段1：MVP - 增强的本地应用与内容系统
**目标：** 发布带有完整营养算法的TestFlight版本
**时间线：** 为算法精度进行扩展开发（8-12周）
**技术栈：** Flutter、Hive（本地存储）、Riverpod v2、Supabase（仅内容）
**当前状态：** ✅ **算法和内容系统完成** → 🚀 **UI开发阶段**

### 核心功能
1. **新手引导功能** ✅ **已实现**
   - 多步骤用户资料收集
   - 性别、年龄/生日、身高、体重
   - 水壶偏好
   - 食物偏好收集（喜欢/不喜欢/愿意尝试）
   - 跨跑前、跑中、跑后类别的12种预定义食物

2. **基于证据的营养算法** ✅ **已完成并增强**
   - **基于ACSM的能量消耗计算**（MET公式）
   - **精确碳水化合物策略**：肠道训练水平（0.7-1.0克/公斤/小时）
   - **动态跑前营养**：时间敏感的碳水化合物加载（0.25-4.0克/公斤）
   - **基于强度的水合**：基于运动强度的400-800毫升/小时
   - **基于持续时间的钠**：智能补充（≤1小时跑步为0毫克/小时）
   - **可配置参数**：所有算法常数可通过后端编辑

3. **胖后端内容系统** ✅ **已实现**
   - **动态内容管理**：所有UI文本无需代码更改即可编辑
   - **算法参数控制**：营养常数可由同事调整
   - **离线优先与后端同步**：内容的Supabase集成
   - **回退系统**：本地默认确保离线功能

4. **本地计划存储** ✅ **已实现**
   - 基于证据的计算生成计划
   - 通过Hive的本地计划存储（多个计划）
   - 计划历史和管理
   - 离线优先架构

5. **反馈系统** ✅ **已实现**
   - 反馈收集的Supabase集成
   - 用户体验跟踪
   - 计划有效性反馈
