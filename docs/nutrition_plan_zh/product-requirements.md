# 产品需求文档

## 1. 产品概述

### 1.1 产品定位
*[来源: README.md, PROJECT_ANALYSIS_FINDINGS.md]*

耐力运动营养规划系统是一个基于科学证据的综合营养规划工具，为跑步、自行车和铁人三项耐力运动员提供个性化的营养方案。系统通过结合运动营养学原理与先进的优化算法，生成实用的赛前和比赛中营养建议。

### 1.2 目标用户
*[来源: README.md, ATHLETE_EXAMPLES.md]*

- 耐力运动员（从休闲到精英水平）
- 支持的运动类型：
  - 跑步运动员（5K到超级马拉松）
  - 自行车运动员（1小时计时赛到多日赛事）
  - 铁人三项运动员（短距离到全程铁人）
- 年龄范围：22-50岁
- 体重范围：45-90公斤
- 经验水平：初学者到高级运动员

### 1.3 核心价值主张
*[来源: README.md, QUICK_START_GUIDE.md]*

- **个性化**：基于运动员特征、赛事细节和食物偏好定制
- **科学性**：基于循证运动营养学研究
- **实用性**：提供真实可行的食物组合和份量
- **全面性**：覆盖赛前和比赛中的完整营养需求

## 2. 功能需求

### 2.1 核心功能
*[来源: README.md, CLAUDE.md]*

#### 2.1.1 多运动支持
- 支持跑步、自行车、铁人三项三种运动类型
- 每种运动有特定的优化策略和计算方法
- 自动适应不同运动的营养需求差异

#### 2.1.2 个性化营养计算
*[来源: Nutrition_Plan_Guidelines.md]*

**输入参数：**
- 运动员基本信息（年龄、性别、体重、身高）
- 活动详情（运动类型、距离、配速/功率、地形）
- 时间安排（赛前进食时间）
- 肠道训练水平（低/中/高）
- 食物偏好（喜欢/尝试/不喜欢）

**输出内容：**
- 赛前营养建议（活动前2-3小时）
- 比赛中补给策略（按小时细分）
- 具体食物组合和份量
- 营养素总量（碳水、蛋白质、脂肪、钠、水分）

#### 2.1.3 食物偏好系统
*[来源: PREFERENCES_GUIDE.md]*

**偏好级别：**
- **喜欢（like）**：优先推荐的食物
- **尝试（try）**：可以接受的食物
- **不喜欢（dislike）**：完全避免的食物

**支持的食物类别：**
- 赛前食物（10种）：燕麦片、华夫饼、贝果、坚果酱、果酱/蜂蜜、香蕉、苹果、果汁、能量棒、咖啡
- 比赛中食物（4种）：水、运动饮料、能量胶、能量软糖

### 2.2 高级功能
*[来源: PRODUCT_ROADMAP.md, README.md]*

#### 2.2.1 优化算法
- 线性规划（LP）求解器进行多目标优化
- 智能约束处理（份量、便携性、种类限制）
- 优雅降级机制（LP失败时使用枚举方法）

#### 2.2.2 按小时精准控制
- 碳水化合物摄入速率（30-90g/小时）
- 水分补充速率（400-800ml/小时）
- 钠补充速率（200-400mg/小时）

#### 2.2.3 比赛物流考虑
*[来源: PRODUCT_ROADMAP.md - Iteration 2]*

- 食物便携性评分（无/低/中/高）
- 赛道补给站可用性
- 自行车携带能力考虑
- 跑步阶段便携性优先

#### 2.2.4 整份优化
*[来源: README.md, PRODUCT_ROADMAP.md - Iteration B, D]*

- 支持容差范围（--margin参数）
- 固体食物偏向整份（苹果、贝果、华夫饼、香蕉）
- 液体保持分数精度
- 工程产品（能量胶/软糖）始终为整数

### 2.3 约束规则
*[来源: PRODUCT_ROADMAP.md - Iteration A, Nutrition_Plan_Guidelines.md]*

#### 2.3.1 赛前膳食规则
- 每个类别最多选择一种：
  - 基础淀粉：燕麦片、贝果、华夫饼、能量棒
  - 水果：香蕉、苹果
  - 涂抹酱：果酱/蜂蜜、坚果酱
  - 饮料：果汁、咖啡
- 物品数量：2-4项
- 限制纤维和脂肪含量

#### 2.3.2 比赛中补给规则
- 物品数量：2-4项（便携性加权）
- 每小时上限：能量胶≤3个，能量软糖≤2.5包
- 跑步阶段优先便携和赛道提供的物品

## 3. 营养学需求
*[来源: Nutrition_Plan_Guidelines.md, README.md]*

### 3.1 宏量营养素目标

| 营养素 | 推荐摄入量 |
|--------|-----------|
| **碳水化合物** | |
| • 赛前 | 1-4g/kg体重（活动前0.25-4小时） |
| • 比赛中 | 30-60g/小时（可达90g/小时，葡萄糖+果糖混合） |
| **钠** | 300-600mg/小时（炎热环境可达1000mg/小时） |
| **液体** | ~0.4-0.8L/小时（取决于出汗率） |

### 3.2 运动特定调整
*[来源: README.md, endurance_fueling.py文档]*

- **跑步**：较低碳水吸收率（30-60g/小时），强调便携性
- **自行车**：较高碳水耐受度（30-90g/小时），可携带更多补给
- **铁人三项**：累积疲劳增加8%能量需求，分段优化

### 3.3 科学计算基础
*[来源: README.md, PROJECT_ANALYSIS_FINDINGS.md]*

- **跑步**：ACSM跑步方程（VO₂ = 0.2 × 速度 + 3.5）
- **自行车**：基于功率或速度的MET值计算
- **游泳**：标准MET值（8-10）
- **能量消耗**：基于MET的精确计算

## 5. 用户场景
*[来源: ATHLETE_EXAMPLES.md, QUICK_START_GUIDE.md, 70.3_race_plan.md]*

### 5.1 典型用户场景

#### 场景1：首次半程马拉松
- 用户：32岁女性，58公斤，跑步新手
- 需求：简单可靠的补给策略
- 输出：2-3种熟悉食物的组合，适中的碳水目标

#### 场景2：马拉松个人最佳
- 用户：40岁男性，75公斤，经验丰富
- 需求：优化的高强度补给方案
- 输出：精确的按小时补给计划，最大化碳水摄入

#### 场景3：70.3铁人三项
- 用户：43岁女性，50公斤，首次尝试
- 需求：多段赛事的综合营养策略
- 输出：分段优化的补给方案，考虑换项和携带限制

### 5.2 特殊需求场景
*[来源: PREFERENCES_GUIDE.md]*

- **GI敏感**：液体为主，低纤维选择
- **素食/纯素**：全植物性食物优先
- **无麸质**：避免含麸质食物
- **低FODMAP**：避免高FODMAP食物
- **咖啡因敏感**：排除含咖啡因物品

## 8. 约束和限制
*[来源: README.md, PROJECT_ANALYSIS_FINDINGS.md]*

### 8.1 技术约束
- 需要Python 3.10+（使用现代语法）
- PuLP库为可选依赖（优雅降级）
- 命令行界面（暂无GUI）

### 8.2 数据约束
- 食物数据库限于14种预定义食物
- 营养信息基于标准份量
- 不支持自定义食物添加

### 8.3 使用约束
- 需要基本的命令行操作知识
- 偏好设置需要JSON格式
- 建议在训练中测试后使用
